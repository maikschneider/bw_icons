# Changelog

## 5.0.0

### Added

- Support for TYPO3 14.3 LTS and PHP 8.5.
- Playwright acceptance tests for the backend icon picker.

### Changed

- Raised the minimum supported TYPO3 version to 13.4.21.
- Reworked icon provider creation and cache access to use dependency injection.
- Updated the CI matrix to cover TYPO3 13.4 and 14.3 on PHP 8.2 through 8.5.

### Removed

- Support for TYPO3 12.
